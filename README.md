# Snack OS downloads

Download the newest version for Windows from **[Releases](../../releases/latest)**: the file `TikTrigz-x.y.z-win-x64.exe`
(Snack OS, with TikTrigz for everything TikTok).

1. Run the `.exe` and follow the installer.
2. Windows may show a SmartScreen warning because the installer is not code-signed: click **More info → Run anyway**.

**Updating:** the app updates itself. When a new version is out, it shows *"Update ready — Restart to update"*.
You can also install a newer `.exe` over the old one at any time. Your settings are kept.

Most features need a TikTrigz Pro key.

*Older versions (up to 01.02.06) were published on [Zephino/TikTrigz-releases](https://github.com/Zephino/TikTrigz-releases).*
