# Snack OS downloads

Get the newest Snack OS for Windows from **[Releases](../../releases/latest)**: the file `SnackOS-<version>.zip`.

1. Unzip it anywhere, for example your Desktop.
2. Open **Snack OS.exe** and press **START**.
3. Windows may warn you because the program is not code-signed: click **More info → Run anyway**.

Nothing to install first: Snack OS brings everything it needs.

**Updating:** Snack OS tells you when a new version is out, in the launcher and at the top of Snack OS. Press
**Update now** and it downloads, updates and starts again by itself. Your settings, gifts and effects stay.

Snack OS needs a licence key.

*Older TikTrigz versions (up to 01.02.06) are on [Zephino/TikTrigz-releases](https://github.com/Zephino/TikTrigz-releases).*
